PITCHQUIZZ

2 Clubs → 1 Joueur

Deux clubs, un joueur à trouver. Tape le nom d'un footballeur qui a joué dans les deux équipes premières : le premier qui trouve remporte la manche.

Jouer maintenantTélécharger sur l'App Store

Gratuit · iPhone et navigateur · 5 langues

Comment jouer

  1. Deux clubs s'affichent, par exemple le PSG et le Real Madrid.
  2. Tape le nom d'un joueur passé par les deux : les noms se proposent dès 3 lettres.
  3. Toutes les bonnes réponses sont acceptées, les fautes de frappe aussi.
  4. Le premier qui trouve gagne la manche. Le plus de manches gagne le match.

Les modes

  • En ligne : affronte un vrai joueur de ton niveau. Une victoire fait monter ta note sur ta carte de joueur.
  • Contre l'IA : entraîne-toi seul, au niveau de ton choix.
  • Entre amis : crée un salon, partage le code et jouez ensemble.

Les niveaux

Quatre niveaux : Facile, Moyen, Difficile et Expert. Plus ta note monte (Bronze, Argent, Or, Légende), plus les questions sont dures. Toutes les données sont vérifiées par deux sources indépendantes.
